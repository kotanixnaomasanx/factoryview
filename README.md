# SFV2026 取材コース

瀬戸内ファクトリービュー2026（11/4〜11/23）の参加企業の見学・ワークショップのコマから、取材コースを組んで共有するためのページです。

- 日別・週ごとにコマを確認し、取材コースを組む
- エリア（複数可）・種別・駅からの距離・取材済みで絞り込み
- 移動時間を見込んだおすすめコースの自動作成（1回きりの企画を優先可）
- 共有リンク、行程テキスト、Googleカレンダー用CSV、Googleマップ経路
- 各社の詳細ページ（factory-view.jp）へのリンク

`index.html` 1ファイルで動きます。GitHub Pages（Settings → Pages → Branch: main / root）で公開できます。

取材済みの印は、このページではブラウザごとに保存されます。駅からの距離・移動時間は町丁目単位の位置からの目安です。
