# SFV2026 コースセレクター

瀬戸内ファクトリービュー2026（11/4〜11/22）の参加企業の見学・ワークショップのコマから、回るコースを組んで共有するためのページです。

- 日別・週ごとにコマを確認し、コースを組む（各企画の概要・予約の要否つき）
- エリア（複数可）・種別・駅からの距離・予約の要否で絞り込み
- 移動時間を見込んだおすすめコースの自動作成（1回きりの企画を優先可）
- 共有リンク、行程テキスト、Googleカレンダー用CSV、Googleマップ経路
- 各社の詳細ページ（factory-view.jp）へのリンク

`index.html` 1ファイルで動きます。GitHub Pages（Settings → Pages → Branch: main / root）で公開できます。

**交通の所要時間・空き状況・各社の情報（日時・場所）は目安・登録時点の情報です。訪問前に必ず各社の詳細ページ等でご確認ください。**

駅からの距離・移動時間は町丁目単位の位置からの目安です。
